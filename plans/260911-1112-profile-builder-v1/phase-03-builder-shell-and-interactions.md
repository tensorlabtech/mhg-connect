# Phase 3: Builder shell and interactions

## Requirements

- [x] Build a single toolbar with navigation, save state, preview, undo/redo, and Publish.
- [x] Add a collapsible Outline, selectable Canvas blocks, and contextual Inspector.
- [x] Support vertical drag-and-drop plus explicit Move up/Move down controls.
- [x] Allow hide/show and reordering for Bio, Contact, and Social while Identity stays locked first.
- [x] Debounced autosave persists drafts and reports saving, saved, dirty, conflict, and error states.
- [x] Mobile uses Preview/Edit modes instead of squeezing desktop columns.
- [x] Allow restoring the last published snapshot without changing the public profile.

## Validation

- Keyboard, focus-visible, dialog/popover, disabled, loading, and error states are exercised.
- Long copy and narrow viewport do not overflow.
